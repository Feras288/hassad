# قواعد مساحة عمل حصاد

تنطبق هذه القاعدة على المشروع بالكامل. اقرأ `@/AGENTS.md` أولاً ثم راجع الوثائق تحت `@/docs/` قبل التعديل.

## حدود العمل

- اعمل داخل مساحة المشروع فقط، واطلب التأكيد قبل الوصول إلى ملفات خارجها أو تشغيل عمليات واسعة.
- لا تقرأ أو تطبع أو تضيف ملفات الأسرار أو بيانات الاعتماد إلى التحكم بالإصدارات.
- لا تستخدم `git reset --hard` أو أوامر حذف واسعة أو عمليات قاعدة بيانات مدمرة.
- لا تشغّل ترحيلات قاعدة البيانات إلا بعد عرض SQL الناتج ومراجعته.

## هندسة التطبيق وجودته

- الواجهة: `client/src/`؛ الخلفية: `server/`؛ القاعدة: `drizzle/`؛ الاختبارات: `server/*.test.ts`.
- أي ميزة محفوظة تحتاج عادةً: المخطط، الترحيل، طبقة البيانات، إجراء tRPC، الواجهة، والاختبار.
- حافظ على العربية RTL والإنجليزية LTR، وحالات التحميل والخطأ والفراغ.
- لا تنشئ روابط HTML متداخلة، ولا بيانات عملاء أو تقييمات أو شهادات وهمية.
- شغّل `pnpm check && pnpm test` بعد التعديل، و`pnpm build` عند تغيير الحزم أو إعدادات البناء.
