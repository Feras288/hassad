# حصاد — منصة المدخلات والخدمات الزراعية

حصاد منصة رقمية للسوق الزراعي السعودي تجمع سوق المدخلات، تشخيص المحاصيل، الخدمات الزراعية، وسوق المحاصيل B2B. يدعم المشروع العربية كواجهة افتراضية باتجاه RTL والإنجليزية باتجاه LTR، ويستخدم قاعدة بيانات لتشغيل المنتجات والحجوزات والمراسلات والطلبات ومحتوى الإدارة.

## التشغيل السريع

| الغرض | الأمر |
| --- | --- |
| تثبيت الحزم | `pnpm install` |
| تشغيل بيئة التطوير | `pnpm dev` |
| فحص TypeScript | `pnpm check` |
| تشغيل الاختبارات | `pnpm test` |
| بناء نسخة الإنتاج | `pnpm build` |
| إنشاء ترحيل Drizzle | `pnpm drizzle-kit generate` |

استخدم Node.js 22 وpnpm. تعتمد المصادقة وقاعدة البيانات على متغيرات بيئة مُدارة من منصة الاستضافة؛ لا تنشئ ملف أسرار محلياً أو ترفعه إلى Git.

## البنية

| الطبقة | الموقع | المسؤولية |
| --- | --- | --- |
| العميل | `client/src/` | صفحات React والواجهة والترجمة والسياق المحلي. |
| API | `server/routers.ts` | إجراءات tRPC وعقودها والصلاحيات. |
| البيانات | `server/db.ts` | استعلامات Drizzle وعمليات الحفظ. |
| قاعدة البيانات | `drizzle/` | المخطط والترحيلات المنظمة. |
| الاختبارات | `server/*.test.ts` | اختبارات Vitest للعقود وسلوك الواجهة. |

راجع [الهندسة](docs/ARCHITECTURE.md) و[دليل التطوير](docs/DEVELOPMENT_GUIDE.md) قبل تغيير أي ميزة. يجد مستخدمو VS Code وGitHub Copilot وClaude Code وGoogle Antigravity تعليمات التجهيز في [دليل التطوير المدعوم بالذكاء الاصطناعي](docs/AI_ASSISTED_DEVELOPMENT.md)، ودليل فك وتشغيل الحزمة محلياً في [التشغيل المحلي](docs/LOCAL_DEVELOPMENT.md).

## قواعد بيانات وإنتاج

أي تطوير يعتمد على الحفظ الدائم يجب أن يمر عبر مخطط Drizzle وترحيل مراجع ومساعد بيانات وإجراء tRPC وواجهة تحتوي حالات تحميل وخطأ وفراغ واختبار. لا تضف بيانات تجريبية أو تقييمات أو ادعاءات غير موثقة إلى واجهة الإنتاج.

المستودع خاص. اتبع `AGENTS.md` عند استخدام أي وكيل ذكاء اصطناعي واربط كل تغيير باختبارات مناسبة قبل إنشاء طلب دمج.
