# التشغيل المحلي لحصاد

هذه الحزمة مخصصة للتطوير عبر **VS Code** وGitHub Copilot وClaude Code وGoogle Antigravity. وهي لا تتضمن كلمات مرور أو مفاتيح أو بيانات قاعدة إنتاج أو مجلدات الحزم والمخرجات؛ تُنشأ هذه العناصر محلياً عند الحاجة.

## بدء العمل

ثبّت Node.js 22 وpnpm، ثم فك ضغط الحزمة وافتح مجلد `hasaad-platform` في VS Code. ثبّت الإضافات المقترحة في `.vscode/extensions.json`، وبعد ذلك نفّذ الأوامر التالية.

```bash
pnpm install
pnpm check
pnpm test
pnpm dev
```

يبني الأمر `pnpm build` نسخة الإنتاج للتحقق قبل دمج التغييرات. لا تنسخ `node_modules` أو `dist` بين الأجهزة؛ أنشئها من جديد بالأوامر السابقة.

## متغيرات البيئة

تحتاج خصائص تسجيل الدخول وقاعدة البيانات والتخزين إلى إعدادات خاصة بالبيئة. أنشئ ملف `.env` محلياً فقط، واحفظ قيمه في مدير أسرار مناسب، ولا ترفعه إلى Git أو تشاركه عبر المحادثات. راجع `server/_core/env.ts` لمعرفة المتغيرات التي يستخدمها وقت التشغيل، واضبط على الأقل اتصال قاعدة بيانات منفصل للتطوير قبل تشغيل أي عمليات كتابة أو ترحيلات.

> لا تتضمن الحزمة بيانات إنتاج أو بيانات تجريبية. تظهر الواجهات بحالات فارغة إلى أن تُضاف سجلات حقيقية إلى بيئة التطوير.

## الوكلاء المساعدون

| الأداة | نقطة البداية في المشروع |
| --- | --- |
| VS Code | `.vscode/settings.json` و`.vscode/tasks.json` |
| GitHub Copilot | `.github/copilot-instructions.md` و`.github/instructions/` |
| Claude Code | `CLAUDE.md` و`.claude/settings.json` |
| Google Antigravity | `GEMINI.md` و`.agents/rules/hassad.md` |

أضف جذر المشروع إلى Antigravity وفعّل قاعدة `.agents/rules/hassad.md` كقاعدة **Always On** من واجهته. لا تتطلب هذه الخطوة تغييراً داخل الكود.

## دورة تغيير آمنة

ابدأ بقراءة `AGENTS.md`، ثم حدّث المخطط والترحيل قبل طبقة البيانات وإجراء tRPC والواجهة والاختبار عند التغييرات المحفوظة. حافظ على العربية RTL افتراضياً، واستخدم بيانات حية أو حالات فارغة بدلاً من المحتوى الوهمي. راجع `docs/DEVELOPMENT_GUIDE.md` و`docs/AI_ASSISTED_DEVELOPMENT.md` للتفاصيل.
